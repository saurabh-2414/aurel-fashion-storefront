# AUREL — Designed to Last

AUREL is a premium minimalist men's fashion storefront homepage built with React. The website features an editorial design aesthetic, thoughtfully curated product collections, and a responsive layout designed for a seamless shopping experience across devices.

## Live Demo

View Live Website: https://aurel-storefront.netlify.app/

## Features

- Responsive design for desktop, tablet, and mobile devices
- Premium minimalist fashion UI
- Interactive hero carousel
- Product category section
- Product listing with reusable product cards
- Category-based product filtering
- Product search functionality
- View All Products functionality
- Hover animations and interactive elements
- Newsletter subscription UI
- Responsive navigation menu
- Smooth scrolling

## Tech Stack

- React.js
- JavaScript
- CSS3
- Vite
- React Icons

## Installation and Setup

### 1. Clone the repository

```bash
git clone: https://github.com/saurabh-2414/aurel-fashion-storefront
```

### 2. Navigate to the project directory

```bash
cd aurel
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

## Design Concept

AUREL follows a minimalist and editorial design philosophy, focusing on timeless fashion essentials rather than trends.

The visual design uses:

- Warm cream backgrounds
- Espresso and earthy tones
- Elegant serif typography
- Minimal layouts
- High-quality fashion imagery
- Subtle transitions and hover effects

## Disclaimer

AUREL is a frontend development project created for educational and assessment purposes. It is a static storefront UI and does not include backend functionality, real payment processing, or actual product purchasing.
